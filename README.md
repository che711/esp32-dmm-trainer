# DMM Trainer

Учебный стенд на ESP32 для отработки функций мультиметра **Brymen BM788BT**
(и любого другого приличного прибора). Стенд выставляет известные величины,
ведёт эталонный лог и умеет проверять ваши измерения: логи мультиметра,
выгруженные по Bluetooth в CSV, автоматически сверяются с паспортной
точностью прибора.

> **Безопасность.** Стенд работает только с напряжениями до 24 В.
> Ни один сценарий не требует сети 230 В и не должен к ней подключаться.
> Режимы, которые без сети не отработать (VFD, NCV, CAT III/IV), честно
> перечислены в [docs/exercises.md](docs/exercises.md).

## Что умеет

| Модуль стенда | Функции мультиметра |
|---|---|
| Прецизионная опора 2,5 В + делитель 1:10, 1:100 | DCV, mV, проверка базовой точности 0,03% |
| MCP4725 (плавное DC 0…3,3 В) | DCV, REC MAX/MIN/AVG, AutoHold |
| ШИМ прямой и через RC-фильтр | ACV, AC+DC, True RMS, крест-фактор, Logic Hz, Duty % |
| Резисторная декада 1 Ом…1 ГОм + обрыв | Ω, прозвонка BeepLit, nS, REL |
| Симулятор дребезга контакта | барграф, AutoHold Real-Read |
| Зоопарк компонентов (диоды, конденсаторы, брак) | диодный тест, ёмкость |
| Коммутируемые нагрузки 10 мА / 500 мА / 2,4 А | µA, mA, A, burden voltage |
| Источник тока 4…20 мА | режим %4-20 мА |
| Фантомный источник через 10 МОм | AutoV / LoZ |
| Нагревательная пластина + вентилятор + DS18B20 | T1, T2, T1−T2, REC |
| Реле пускового тока | CREST (пик от 0,25 мс) |

## Структура репозитория

```
firmware/src/        прошивка (Arduino core 3.x / pioarduino)
  hal/               аппаратный слой: один класс на модуль
  scenario.*         движок сценариев и ground-truth лог
  faults.*           режим «найди неисправность»
  webapi.*           REST API и раздача UI
data/index.html      web UI (LittleFS)
scenarios/*.json     сценарии обучения
tools/               Python-пакет: разбор CSV и выставление оценки
scripts/             валидация сценариев, сборочные хуки
docs/                схемотехника, упражнения, описание API
```

## Быстрый старт

```bash
git clone https://github.com/che711/esp32-dmm-trainer
cd esp32-dmm-trainer

pio run -t upload            # прошивка
pio run -t uploadfs          # web UI + сценарии в LittleFS

# стенд поднимет точку доступа dmm-trainer / trainer123
# UI: http://192.168.4.1/
```

Для работы в домашней сети пропишите `WIFI_STA_SSID` / `WIFI_STA_PASS`
в `firmware/src/config.h` — при неудачном подключении стенд всё равно
поднимет свою точку доступа.

## Цикл обучения

1. Открыть UI и выбрать сценарий — например, `dcv_ladder`.
2. Подключить щупы к указанным клеммам, включить на BM788BT
   BLE-Comm (долгое нажатие кнопки Bluetooth) и запись в приложении.
3. Стенд отрабатывает шаги, показывая подсказки; параллельно пишет эталон.
4. Экспортировать CSV из приложения Brymen, скачать `truth.csv` со стенда.
5. Сверить:

```bash
cd tools && pip install -e .
dmm-trainer fetch -o truth.csv
dmm-trainer grade --meter brymen_export.csv --truth truth.csv -v
```

```
----------------------------------------------------------------------------------
Пройдено: 6   Провалено: 1   Пропущено: 0
```

Допуск считается по таблице точности из руководства BM788BT
(`tools/dmm_trainer/spec.py`): для каждого показания выбирается предел,
на котором работал бы автовыбор, и применяется паспортное
±(% от показания + N единиц младшего разряда).

Сдвиг между логами подбирается автоматически — стенд и мультиметр
стартуют независимо, синхронизировать их вручную не нужно.

## Режим «найди неисправность»

Стенд вносит один скрытый дефект (обрыв, КЗ, пробитый диод, усохший
конденсатор, дребезг, фантомное напряжение, просевшая опора, обрыв
токовой петли) и показывает только симптом. Вы ищете причину мультиметром
и ставите диагноз в UI; после верного ответа стенд рассказывает, каким
режимом это ищется быстрее всего.

## Железо

Схемотехника узлов, номиналы и разводка клемм — в
[docs/hardware.md](docs/hardware.md). Распиновка правится в одном месте:
`firmware/src/config.h`. Минимальная версия v1 (опора, декада, диоды, ШИМ)
собирается на макетке за вечер и уже закрывает половину функций прибора.
